## 케이블TV

### 1. 운영 구조
| 사업자 | 역할 |
| --- | --- |
| PP(방송채널사용사업자) | 보도·영화·스포츠·교양·오락 프로그램을 공급 |
| SO(종합유선방송국) | 프로그램을 공급받아 시청자에게 전송 |
| NO(전송망사업자) | PP와 SO, SO와 시청자 사이의 망을 연결 |

- 세분화된 오디언스를 대상으로 하며, 지상파와 달리 마이크로 마케팅·다이렉트 마케팅에 용이
- 광고 길이를 다양하게 운영할 수 있고 인포머셜 형태도 가능

### 2. 지상파와의 광고 규정 비교

| 내용 | 지상파 TV | 케이블TV |
| --- | --- | --- |
| 프로그램 광고 | 방송순서 시간의 10/100 이내 | 방송 시간과 무관하게 시간당 최대 10분(어린이 대상 6분) |
| 토막(스팟) 광고 | 시간마다 2회 이내, 매회 4건 | 시간당 2회 이내, 매회 5건 이내 |
| ID 광고 | 매시간 6회, 1회 10초, 자막 화면의 1/4 | 시간당 4회, 1회 10분 이내, 자막 화면의 1/4 |
| 중간 광고 | 스포츠 중계 외 금지 | 프로그램 길이에 따라 45~60분 미만 1회, 60~90분 미만 2회, 120분 이상 4회, 매회 3건 이내·회당 1분 이내 |

### 3. 장단점

| 장점 | 단점 |
| --- | --- |
| 세분화된 타깃 오디언스 | 시간적 한계(일회성) |
| 저렴한 요금 | 지상파보다 낮은 방송의 질 |
| 광고 길이의 유연성 | 많은 채널 수로 채널당 시청률이 낮음 |
| 인포머셜·직접 반응 광고 가능 | 클러터가 높고 지역 저예산 광고와 함께 방송될 수 있음 |
| 변형 광고 가능 | 광고 회피 심화(Zipping & Zapping) |

- **인포머셜**: 충분한 정보를 제공하는 긴 광고
- **직접 반응 광고**: 080 등 번호로 전화를 유도하는 형태

### 4. 요금
- 실단가를 쓰는 OCN·YTN 같은 채널은 요금이 제시되나, 많은 채널이 주먹구구식 판매
- 단가를 높게 책정한 뒤 적게는 몇백, 많게는 2,000%의 보너스를 제공하기도 함
- 보너스 2,000%는 판매한 광고의 20배가 방송된다는 뜻(200만원 1회 구매 시 20회 집행)
- 모든 채널이 실단가를 쓰는 것이 바람직

## 위성TV

- 1995년 무궁화위성 1호 발사 후 시험 방송, 2002년 스카이라이프 영업 시작, 2009년 IPTV 서비스 시작
- IPTV 광고비는 2021년 1,070억원 규모에서 2023년 1,053억원으로 소폭 감소
- IPTV 광고는 VOD 광고(점유율 39%대)와 큐톤 광고(60%대)로 나뉨
- 위성TV 광고 영업은 PP가 담당하며 스카이라이프 자체는 본격적 영업에 참여하지 않음

| 장점 | 단점 |
| --- | --- |
| 150개 이상의 다양한 채널 | 채널 수가 많아 채널당 시청률이 케이블보다 낮음 |
| 전파 전달의 방해물이 없음 | 충분한 가입자 미확보 |
| 높은 주파수 대역과 디지털화로 인터넷 접속·쌍방향 서비스 가능 | 콘텐츠의 질적 문제, 높은 클러터, 광고 회피 심화 |

- 요금은 1회 기준 판매가 아니라 월 단위 패키지(예: 월 500만원에 약 40회)로 판매되는 경우가 많고 할인이 다양함
- 효과 측정은 피플미터로 하지만 표본 규모의 한계로 정확한 추정이 어려움
- 디지털화로 SO가 셋톱박스를 통해 지역 시청 데이터를 수집할 수 있게 됨

## 인터넷

### 1. 위상
- 광고 분야에서 가장 빠르게 성장한 쌍방향 리얼타임 매체
- 2022년 국내 총광고비 15조 7,678억원 중 온라인 점유율 50.9%, 2023년에는 16조 8,981억원 중 52.3%로 전망
- 네이버 등 대형 포털에 다수 광고주가 브랜드를 노출하며 시장이 활성화

### 2. 광고의 종류

| 종류 | 내용 |
| --- | --- |
| 배너 | 웹페이지 특정 위치에 사각형 띠 모양으로 집행 |
| 팝업 | 페이지 접속 시 새 창이 자동으로 열려 메시지 전달 |
| 이메일 | 수용자 메일로 HTML 문서·이미지·소리·동영상 등 멀티미디어 메시지 전달 |
| 동영상 | 배너보다 역동적, 실제 영상물을 페이지·서브페이지·로딩 광고로 활용 |
| 리치미디어 | 텍스트·그래픽·애니메이션을 넘어 멀티미디어로 풍부한 메시지 전달 |

### 3. 장단점

| 장점 | 단점 |
| --- | --- |
| 시간적·공간적 한계 극복 | 전체 도달률이 낮음 |
| 멀티미디어 이용 가능 | 20~30대를 제외한 연령층, 컴퓨터에 익숙하지 않은 층에 도달하기 어려움 |
| 수용자의 선별성이 높음 | - |
| 피드백과 정보 용량이 큼 | - |
| 비용이 저렴 | - |

### 4. 요금과 효과
- 주요 포털 초기 화면 상단 배너는 1주일에 약 1,000만원 이상, 대부분 CPM 기준
- 풀로 고정되는 배너는 하루 6천만~7천만원
- 구글 등 일부는 클릭률에 따라 요금을 책정
- 효과는 사이트 방문자 수를 이용하거나, 클릭해 정보를 접한 수를 추정하는 방식
- 클릭해 정보를 접한 비율이 **Click Through Rate**이며 이 비율로 요금이 조정되기도 함

## 옥외 광고와 교통 광고

### 1. 옥외 광고
- 1970년대 시작, 1986년 아시안게임·1988년 올림픽·1993년 엑스포를 계기로 기틀 마련
- 1985년 서울올림픽 진흥기금 조성 목적으로 옥상 빌보드, 전광판, 버스·택시 외부 광고가 허가
- 종류: 빌보드(옥상·야립), 전광판(LED·큐보드), 교통 광고, 스포츠 광고(야구장·골프장·축구장 등), 특수 광고(비행선·점보트론·네온·애드벌룬 등)

| 장점 | 단점 |
| --- | --- |
| 노출 효과와 주목률이 높음 | 많은 정보 제공이 불가능하고 상기도가 낮음 |
| 장기간 같은 메시지로 반복 소구 | 법적·공간적 제한으로 좋은 위치 확보가 어려움 |
| 지역 밀착형으로 특정 지역 공략 | 초기 시설 투자가 과다 |
| 4대 매체를 보완해 재인 효과를 높임 | 광고 효과 측정이 어려움 |
| 매체가 다양해 타깃·표현에 맞는 선택 가능 | - |
| 신소재·신규 매체로 주목률과 화제성 유발 | - |

- 국내는 옥외 광고 효과의 적절한 측정·조사가 이루어지지 않음
- 우선 도보·차량 유동 인구를 정확히 파악하는 조사가 주기적으로 필요
- 외국은 일일 교통량, 평균 차량 탑승 인원, 특정 광고물 노출 비율을 산출하며, 미국 등은 유사 데이터를 DEC라는 이름으로 제시해 효과 평가와 집행에 활용

### 2. 교통 광고
- 버스·지하철 등 차량 내외부, 정류장·역사·플랫폼에 광고물을 부착해 이용자와 통행자에게 전달

| 장점 | 단점 |
| --- | --- |
| 지역에 따라 전달 대상을 세분화 | 대중교통을 이용하지 않는 계층에는 전달이 어려움 |
| 시장 현장에서 광고 가능 | 세분화된 표적 소비자에게 전달하기 어려움 |
| 높은 빈도 달성, 구매 시점에서 광고 | 메시지 전달의 한계와 치열한 광고 경쟁 |
| 도시에서 수용자에 대한 집중적 접근 | 효과 측정 기반이 약함 |
| 반복으로 인한 효과, 접촉 시간이 길고 주목률이 높음 | - |
