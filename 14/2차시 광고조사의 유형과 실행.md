## 광고 조사의 유형

| 분류 기준 | 유형 |
| --- | --- |
| 조사의 기본 목적 | 탐색적 조사, 기술적 조사, 설명적 조사 |
| 자료의 특성 | 1차 조사, 2차 조사 |
| 자료 수집 방법 | 정성 조사, 정량 조사 |
| 조사 시점 | 사전 조사, 사후 조사 |
| 조사 횟수 | 횡단 조사, 종단 조사 |
| 조사 대상자의 범위 | 전수 조사, 표본 조사 |

### 1. 기본 목적에 따른 분류

| 유형 | 목적과 상황 |
| --- | --- |
| 탐색적 조사 | 새로운 광고주를 맡거나 경쟁 프레젠테이션을 앞두고 사전 지식이 없을 때 문제 규명과 전략 방향 파악 |
| 기술적 조사 | 특정 제품·광고 정보를 파악·검증해 전략을 실행. 주로 빈도 분석으로 현상·현황 분석 |
| 설명적 조사 | 변수 간 인과 관계나 특정 상황을 예측. 인과적 조사라고도 하며, 프로모션 집행 전 변수의 결과 예측에 필요 |

### 2. 자료의 특성에 따른 분류
- 1차·2차는 첫 번째·두 번째라는 뜻이 아니라 주조사와 보조 조사의 의미

| 구분 | 내용 | 특징 |
| --- | --- | --- |
| 1차 조사 | 담당자가 소비자를 대상으로 직접 자료를 수집·분석 | 시간과 비용이 많이 들지만 목적에 맞는 자료 확보. 정량(면접·전화·인터넷 설문)과 정성(개인·집단 심층 면접) |
| 2차 조사 | 기존의 모든 자료를 확보·분석 | 서적, 정기 간행물, 인터넷 검색, 유료 데이터. 실무에서는 2차로 미리 확보하고 부족할 때 1차 진행 |

### 3. 자료 수집 방법에 따른 분류

| 구분 | 내용 | 결과 형태 |
| --- | --- | --- |
| 정량 조사 | 소비자 의견을 통계적으로 파악, 응답에 숫자를 부여하고 통계 분석 | 빈도, 퍼센트, 평균 점수 |
| 정성 조사 | 소비자 의견을 언어로 심층 파악, 소수 대상의 동기·의견에 집중 | 질적 의미의 글. FGI, 개인 심층 면접 |

### 4. 조사 시점에 따른 분류
- **사전 조사**: 제작·집행 전에 실시. 제작 초기 효과적 대안 선택, 또는 사후 조사와 비교할 기준 마련
- **사후 조사**: 캠페인 진행 후 실시. 종료 후 일정 시간이 지난 시점에 광고 접촉 여부, 브랜드 인지도·선호도, 제품 사용·태도를 측정해 목표 달성 여부 확인과 개선 자료 확보

### 5. 조사 횟수에 따른 분류

| 구분 | 내용 | 예 |
| --- | --- | --- |
| 횡단 조사 | 특정 시점에 한 번 실시. 자료 수집이 용이하고 짧은 시간에 가능 | 대부분의 구매·소비 실태 및 효과 조사 |
| 종단 조사 | 동일 대상(패널)을 시점을 달리해 반복 조사, 시간에 따른 변화 측정 | TV 시청률 조사 |

### 6. 조사 대상자의 범위에 따른 분류
- **전수 조사**: 조사 대상 모두를 대상으로 실시. 인구주택총조사, 특정 지역 모든 건물의 안전 조사
- **표본 조사**: 일부를 뽑아 모집단을 추정. 여론조사, 출시 제품 일부를 무작위 검사
- 확률 표본 추출은 모든 대상이 선정될 확률이 동일, 비확률 표본 추출은 조사자의 판단·편의에 따름

## 광고 조사의 실행

| 단계 | 내용 |
| --- | --- |
| 문제 인식 | 광고주 담당자가 먼저 인식해 대행사에 의뢰하거나, 대행사가 광고주에게 제기. 탐색적·2차 조사를 거쳐 실시 여부 결정 |
| 조사 계획 수립 | 조사 계획서에 배경, 목적, 자료 수집 방법, 조사 대상자, 일정·비용, 주요 내용을 기입. 광고주 승인 후 진행 |
| 조사 준비 | 정성 조사는 조건에 맞는 대상자 섭외와 인터뷰 가이드라인 완성, 설문은 면접원 섭외와 설문지 완성. 필요 시 사전 조사로 수정·보완 |
| 조사 진행 | 연구원이 전체 자료 수집을 감독, 실사팀이 소비자를 대상으로 수집 |
| 결과 분석 | 정성은 인터뷰 내용 정리와 녹취록·요약본, 정량은 코딩·펀칭을 거쳐 데이터화해 통계 분석, 결과 보고서와 데이터 파일 제공 |
| 결과 보고 | 대행사 담당자가 조사 결과와 추가 분석으로 보고서 작성. 조사 보고서, 전략 보고서, 광고 기획서 등으로 완성되며 제본해 전달, 요청 시 프레젠테이션 |
