## DMB

- 이동멀티미디어방송. 개인형 미디어이자 디지털 멀티미디어이며 이동이 가능하다는 특징
- 주파수에 따라 지상파DMB(초단파)와 위성DMB(극초단파)로 구분, 전국을 도달 권역으로 삼음
- 지상파DMB 광고비는 2021년 22억원, 2023년 25억원으로 소폭 상승했으나 다른 매체에 비해 활용도가 낮음

| 장점 | 단점 |
| --- | --- |
| 이동형 광고 | TV에 비해 화면 크기가 매우 작음 |
| 타 매체보다 저렴한 광고비 | 시청 시간과 맞지 않는 광고 노출 |
| 양방향 광고 가능 | - |
| 광고에 대한 몰입도가 높음 | - |

## IPTV

- 2008년 9월 KT·하나로텔레콤·LG데이콤이 사업자로 선정되며 공식 출범
- 실시간 IPTV 가입 가구 200만 돌파에 1년 4개월이 걸려, 케이블TV·위성TV의 약 5년보다 매우 빠름
- 통신사의 유무선 결합 상품 마케팅이 성장을 이끌었고, 방송 환경도 쌍방향 커뮤니케이션 시대로 전환

### 1. 광고의 종류

| 종류 | 내용 |
| --- | --- |
| 점퍼(트리거) | 화면에 배너를 삽입해 리모컨 클릭으로 다른 화면으로 이동 |
| 팝업 | 큰 창이 시청 도중 등장해 배너보다 주목률이 높고, 클릭으로 다음 페이지 이동 |
| 빅 이벤트 배너 | 시청 메뉴란에 텍스트·그래픽을 삽입해 클릭 유도 |
| 브랜드 채널 페이지(DAL) | 특정 제품·광고주의 상세 정보를 담은 사이트, 원하는 만큼 정보 검색이 가능해 능동적 참여를 전제로 높은 효과 기대 |

### 2. 장단점

| 장점 | 단점 |
| --- | --- |
| 저렴한 광고비 | 가입자 수 불충분 |
| 양방향 커뮤니케이션 | 신유형 광고의 제한 |
| 신유형 광고를 통한 브랜드 이미지 개선 | 콘텐츠 산업 육성 등 경쟁 매체와의 차별성 부족 |

## 직접우편 광고

- 우편·운송 서비스로 수용자에게 직접 메시지를 전달하는 모든 형태
- 판매 편지, 브로슈어, 사보, 카탈로그 등
- 사각형 편지 형태를 넘어 동전·로켓·로봇·자동차 모양 등으로 발전

| 장점 | 단점 |
| --- | --- |
| 구매 가능성이 높은 사람만 대상으로 할 수 있음 | 주소록 확보가 어려움 |
| 다양한 모양·형태, 판매촉진과의 결합 가능 | 제작 비용이 많이 듦 |
| 제작 수량·크기를 광고주가 철저히 통제 | 쓰레기 우편(junk-mail)으로 전락하기 쉬움 |
| 다른 매체와 달리 광고 효과 측정이 용이 | 적절한 배달 시기를 맞추기 어려움 |

## PPL

- 영화·드라마에 등장하는 주인공이 특정 브랜드를 이용·구매하는 장면으로 인지도와 선호도를 높임
- 간접 광고보다 PPL이라는 용어가 더 정확한 표현
- 국내 성공 사례: SK텔레콤, 초코파이, 야쿠르트의 제품 PPL, 이효리가 프로그램에서 착용한 뉴발란스

| 장점 | 단점 |
| --- | --- |
| 광고라는 인식 없이 자연스럽게 노출 | 소비자를 기만한다는 오해의 소지 |
| 영화·드라마 관람층과 타깃이 일치하면 효과가 큼 | 시청자의 시청권을 해칠 수 있음 |
| 콘텐츠가 흥행하면 전 세계 노출 가능 | 브랜드 이미지에 부정적 영향을 줄 수 있음 |

## 모바일 광고

- 스마트폰 등 휴대전화 기기를 통한 광고, SMS 텍스트 광고나 모바일 웹사이트 배너 형태
- 광고비는 2021년 6조 2,239억원에서 2023년 7조 3,414억원으로 상승
- 대부분이 스마트폰을 쓰고 실시간으로 노출과 구매가 가능하다는 점에서 효과성이 큼
