## 크리에이티브란

- 시장·경쟁사·소비자를 바탕으로 치밀하게 짜인 전략을 소비자에게 효과적으로 전달하는 기능
- 제품이 가진 편익과 소비자가 바라는 욕구 사이에 이미 존재하는 관계를 새롭고 전략적으로 재구성하는 것
- 그래서 광고를 과학적 전략이자 예술적 크리에이티브라고 함
- **전개 과정**: 광고주는 마케팅·제품 콘셉트를, 대행사는 소비자를 바탕으로 광고·크리에이티브 콘셉트를 만든다

## 매체별 크리에이티브 표현

### 1. 인쇄 광고
언어적 표현과 시각적 표현으로 나뉜다.

| 언어 요소 | 역할 |
| --- | --- |
| 헤드라인 | 가장 큰 글자로 눈길이 먼저 닿는 곳에 위치, 가장 먼저 읽힐 가능성이 높음 |
| 서브 헤드라인 | 주의를 이어 본문을 읽게 함. 헤드라인만으로 뜻이 전달되지 않을 때 보완하며 생략되기도 함 |
| 바디 카피 | 구체적 메시지 전달, 상세 설명. 구성 요소 중 가장 많은 공간 차지 |
| 슬로건 | 캐치프레이즈. 브랜드 관리를 위해 여러 편의 광고에서 계속 사용(나이키 'Just do it', 유한킴벌리 '우리 강산 푸르게 푸르게') |
| 캡션 | 사진·일러스트 주위의 작은 글자로 주제를 서술·설명 |

- 시각적 표현의 기능: 비주얼의 아름다움과 임팩트로 주의와 흥미 유발, 콘셉트 전달 강화, 제품 특징의 시각적 제시, 사진으로 리얼함이나 무드로 감정 소구, 브랜드 개성 조성, 컬러로 전달 효과 제고, 컴퓨터 그래픽 활용, 비주얼과 카피의 레이아웃
- **레이아웃**: 글자의 서체·크기·자간·행간, 사진·일러스트 선정, 시각 요소의 위치·배열·색채 결정

### 2. 전파 광고
- 인쇄 광고는 언어·시각 중심이지만 전파 광고는 청각적 표현이 추가됨
- TV는 언어·시각·청각을 모두 쓰는 종합 예술적 성격, 라디오는 언어와 청각 요소만 사용
- 중요한 것은 전달하려는 메시지를 어떤 형식으로 표현하느냐

#### 전파 광고의 표현 방식

| 유형 | 내용 |
| --- | --- |
| 직접 소구형 | 소비자 약속을 직접 주장. 권위적·독단적일 수 있으나 제작이 간편하고 비용이 적음. 뉴스 발표식은 새 내용 고지에 효과적 |
| 대화형 | 대화·인터뷰 형식. 당사자는 연예인·권위자·일반 소비자 모두 가능, 친근하게 다가감 |
| 증언형 | 유명인·권위자·소비자가 제품을 직접 증언. 권위자는 제품과 연관된 사람이 좋음 |
| 드라마형 | 스토리텔링으로 기억도를 높임. 내레이션·극화, 기승전결의 감정 곡선 |
| 문제 해결형 | 문제를 먼저 제시하고 해답으로 제품 등장 |
| 생활 단편 제시형 | 공감할 수 있는 생활의 한 단편 제시, 자연스럽게 자기 생활의 일부라는 학습 효과 |
| 실연형 | 사용 방법을 직접 보여 줌(데몬스트레이션형) |
| 비교형 | 비교로 객관성과 신뢰성 부여, 차이가 확실할 때만 활용 |
| 상징형 | 주로 시각적 자극으로 감각에 호소 |
| 스펙터클형 | 압도적 장관 연출, 대규모 뮤지컬 방식이 대표적이며 젊은 층에 효과 |
| 특수 효과형 | 새롭고 신기한 제작 기법으로 주의와 관심 유도 |

- **라디오 광고**: 시각 효과를 쓸 수 없어 광고 문안의 중요성이 크고, 메시지와 오디오의 독창성, 청취자의 상상력 유도가 중요

### 3. 인터넷 광고
- 국내 광고 시장에서 지상파 TV, 신문에 이은 세 번째 매체
- 기능과 효과: 친밀하고 계속적인 서비스 제공, 브랜드 이미지 소구, 전 세계적 도달 범위, 시간·공간의 무제한성, 충성도를 높이는 접근, 상세 정보 제공과 흥미 부여
- 1:1 커뮤니케이션 매체이므로 개인의 욕구를 채우는 노력이 필요
- 밀어붙이는 플로팅 광고보다 사용자 주도형 인터랙티브 광고가 호감을 삼
- 제작 단계: 광고주와 제작 내용 협의 → 초기 계획안 수립 → 크리에이티브 브리프 작성 → 이벤트 페이지 제작·프로그래밍 → 관리자 페이지 제작 → 배너 제작 및 매체별 사이즈 변화 → 미디어랩에 배너 게재 요청 → 이벤트 운영 관리 및 결과 레포팅

## 크리에이티브 전략 수립의 모형

### 1. T-Plan
다섯 단계를 순환하는 모형.

| 질문 | 단계 |
| --- | --- |
| 우리는 현재 어디에 있는가? | 시장 상황 분석 |
| 우리는 어디로 갈 수 있는가? | 광고 목표 설정 |
| 어떻게 그곳에 갈 수 있는가? | 광고 전략 수립 |
| 우리는 지금 그곳에 가고 있는가? | 크리에이티브 실행 |
| 왜 우리는 그곳에 있는가? | 결과 평가 |

- 크리에이티브 단계에서 답할 질문: 누구에게 이야기할 것인가, 목표 소비자가 어떻게 생각하도록 할 것인가, 광고가 해결할 문제는 무엇인가, 가장 중요한 반응과 그 근거는 무엇인가, 광고는 어떤 개성을 가져야 하는가

### 2. The Brief
- 정확히 1장으로 된 간단한 브리프 양식
- 크리에이티브 팀의 의문점에 단적으로 답하고, 제작진에게 가장 간결하고 정확한 전략적 방향을 제시

| 항목 | 내용 |
| --- | --- |
| 주소구 대상 | 인구통계 자료와 라이프스타일, 심리·행동 양식. 정확한 광고 전략의 출발점 |
| 소비자 기존 관념 | 소비자가 느끼는 현재의 심리 상태, 상품의 장단점, 경쟁 상품과 관련한 태도·이미지 |
| 광고 목표 | 광고가 할 수 있고 해야 하는 것을 명확히 규정 |
| 크리에이티브 전략 | 소구 대상이 꼭 기억해야 할 단 한 가지 메시지, 가장 강력하고 '뭔가 다른' 단문. 광고는 이 한 가지 제안을 드라마틱하게 표현하는 것 |
| 크리에이티브 전략의 뒷받침 | 한 가지 제안을 뒷받침할 분명한 사실과 증거 |
| 광고물에 들어가야 할 내용 | 법적 규정 조항, 전화번호, 사이트 주소 등 광고주 요구 사항 |
| 브랜드 이미지 | 광고를 접한 뒤 브랜드에 갖게 될 바람직한 이미지. 기존 이미지를 분석하고 왜 그렇게 느끼는지 파악 |
| 일자·결재 | 기획팀과 광고주의 충분한 토론과 합의 후 제작에 들어감 |
