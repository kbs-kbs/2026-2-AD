## 아이디어 발상의 준비

잭 포스터의 '잠자는 아이디어 깨우기'가 제시하는 크리에이티브 힌트 일곱 가지.

| 지침 | 내용 |
| --- | --- |
| 틀에서 벗어나라 | 9년 동안 매일 다른 길로 출근한 사람처럼, 늘 듣지 않던 라디오·아동도서·평소 함께 가지 않던 사람과의 점심을 시도 |
| 무언가를 새로운 눈으로 보라 | '본 것'을 매일 기록. 공책이 가득 차면 읽어 보고 다시 채워 나감 |
| 시각적으로 생각하라 | 아인슈타인은 언어로 생각한 적이 없고, 개념이 이미지로 떠오르면 언어·공식으로 표현 |
| 있지도 않은 경계선을 긋지 말라 | 지레짐작으로 스스로 함정을 파지 말 것 |
| 약간의 제한을 두라 | 지나친 자유는 혼돈. 범위를 정해 두어야 착수할 수 있음 |
| 규칙을 깨 버려라 | 피카소가 여인 얼굴을 그리는 규칙을 깬 것처럼 |
| 다른 분야로 눈을 돌려 도움을 받으라 | 증기선의 프로펠러 회전 계수 장치에서 원리를 얻어 금전등록기를 개발 |

- 아이디어 발상이란 머릿속에 있는 아이디어를 꺼내 보는 작업
- 왼쪽 두뇌는 논리·언어·순서·직선·객관적으로, 오른쪽 두뇌는 상상력·감정·직관·통찰로 정보를 처리하며, 광고 아이디어에는 두 측면을 동시에 고려해야 함

## 다양한 아이디어 발상법

| 기법 | 내용 |
| --- | --- |
| 브레인스토밍 | 오스본이 주장한 집단적 발상 기법, 광고 창작에서 가장 자주 활용 |
| 브레인라이팅 | 독일 호리겔이 창안한 '6·3·5법'. 6명이 5분마다 3개씩 아이디어를 적어 옆으로 넘김 |
| 입출법 | 미국 GE가 자동장치 설계용으로 개발, 강제 연상으로 확산 사고와 수렴 사고를 반복 |
| 시네틱스법 | 고든이 고안, 이질적인 것을 연결·통합하는 결합·합성 기법 |
| 만다라 발상법 | 9칸 정사각형의 가운데에 주제를 적고 주변 칸을 연상으로 채운 뒤, 단어와 주제의 연결을 찾음 |
| 연상법 | 유사('지폐-수표'), 반대('흑과 백'), 근접('지폐-지갑') 개념으로 연상 |
| 결점·희망 열거법 | 결점이나 희망 사항을 열거해 더 나은 아이디어를 얻음 |
| 특성 열거법 | 명사적(전체·부분·재료), 형용사적(성질), 동사적(기능) 특성을 조합 |
| 체크리스트법 | 미리 만든 체크리스트에 하나씩 대입, 대표적으로 SCAMPER |

### 1. 브레인스토밍
진행 순서: 5~20명으로 동질적인 팀 구성(너무 뛰어난 사람은 넣지 않음) → 리더와 서기 선발 → 칠판을 향해 둘러앉기 → 워밍업으로 자유로운 분위기 조성 → 문제 제시 → 아이디어가 떠오르면 즉시 말하고 서기가 기록 → 한 주제에 30분~1시간 → 휴식 후 재개 → 평가 회에 아이디어 전달 → 분류·평가

규칙 네 가지:
- **자유분방**: 엉뚱할수록 환영, 상식에 얽매이지 않음
- **질보다 양**: 좋고 나쁨을 개의치 않고 많이 말함, 양이 많아야 조합 가능성이 높아짐
- **비판 엄금**: 제안된 아이디어를 절대 비판하지 않음
- **결합 개선**: 히치하이크. 남의 아이디어에 자극받아 더 발전시킴

### 2. 브레인라이팅(6·3·5법)
- 주제를 모두 볼 수 있는 곳에 게시 → 진행 방법 설명 → 각자 시트의 ABC란에 5분간 아이디어 기입 → 5분 후 시트를 왼쪽으로 전달, 다른 사람의 글에서 힌트를 얻어 다시 발상 → 넘겨받은 카드의 좋은 아이디어에 O 표시
- 말없이 진행하는 침묵의 발상법

### 3. SCAMPER 체크리스트

| 요소 | 질문 |
| --- | --- |
| Substitute | 다른 것으로 대체하면 어떨까 |
| Combine | 서로 다른 두 가지를 결합하면 어떨까 |
| Adapt | 새 용도·상황에 맞추거나 적응시키면 어떨까 |
| Modify | 기존의 것을 수정·변경하면 어떨까 |
| Put to other uses | 전혀 다른 용도로 쓸 수 없을까 |
| Eliminate | 한두 요소를 제거하면 어떨까 |
| Reverse | 거꾸로 뒤집거나 반대로 하면 어떨까 |
