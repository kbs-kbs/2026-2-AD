## 소비자 의사 결정의 유형

모든 구매가 5단계를 충실히 거치는 것은 아니며, 관여도에 따라 확장적 문제 해결과 습관적 의사 결정으로 갈린다.
**관여도**: 소비자가 특정 대상에 대해 상황에 따라 형성되는 개인적 관심과 중요성을 지각하는 정도.

| 구분 | 확장적 문제 해결 | 습관적 의사 결정 |
| --- | --- | --- |
| 예 | 새 자동차 | 라면 |
| 관여도 | 높음 | 낮음 |
| 인지된 위험 | 높음(고가의 복잡한 제품) | 낮음(단순하고 낮은 가격) |
| 정보 처리 | 세밀한 정보 처리, 정보 탐색 활발 | 주변적 단서 처리(판촉, 진열) |
| 학습 모델 | 인지적 학습 | 행동적 학습 |
| 마케팅 전략 | 광고를 포함한 다양한 정보원으로 세부 정보 제공 | 구매 시점·진열대 광고 등 주변적 단서 제공 |

### 1. 확장적 문제 해결
- 높은 관여도와 인지된 위험을 동반한 결정으로, 대체로 고가 제품이 해당
- 되돌리기 어렵고 손실이 크다고 생각할수록 심사숙고하며 정보를 많이 찾고 의사 결정 시간이 김
- 외적 정보 탐색: 인터넷·모바일 정보 탐색, 주변 사람의 의견, 매장 방문, 판매원 상담
- 광고 전략: 세부 정보를 제공하는 방향으로 수립, 여러 매체로 차별적 정보 제공, 인지된 위험을 줄이기 위해 신뢰와 안정성 강조

### 2. 습관적 의사 결정
- 낮은 관여도와 인지된 위험. 가격이 낮고 자주 사는 제품으로, 잘못 결정해도 손해가 작음
- 제품이 단순해 필요한 정보가 적고 의사 결정 시간이 짧음
- 정보 처리보다 매장 진열, 프로모션 같은 주변적 단서에 영향을 받아 습관적으로 구매
- 평소 본 TV·모바일 광고나 매장 프로모션 메시지가 최종 선택에 결정적일 확률이 높음
- 광고 전략: 쉽게 기억할 단서 제공, 구매 시점의 결정을 돕는 메시지와 판매촉진

## 내부적 영향 요인

| 요인 | 내용 |
| --- | --- |
| 인지 | 감각 기관으로 받은 정보를 선택·체계화·해석하는 과정. 기계적 노출과 인지적 노출로 구분 |
| 학습 | 정보나 경험에 의한 행동의 변화. 의도적 행동뿐 아니라 반복 노출을 통한 비의도적 학습도 발생 |
| 태도 | 특정 대상에 대한 호의적·비호의적 감정. 광고에 긍정적 태도가 형성되면 브랜드 태도와 구매 가능성도 높아짐 |
| 동기 | 목표 지향 행동을 활성화해 욕구를 만족시키는 내적 상태. 매슬로우 5단계 욕구가 대표 모형 |
| 개성 | 개인 고유의 심리적 특성. 외부 환경에 대한 인식과 반응의 차이를 만듦 |
| 연령 | 구매 결정에 가장 강력한 영향 요인 중 하나. 연령대에 맞춰 특정 제품의 구매 욕구가 형성 |
| 라이프스타일 | 가치·취향·선호를 반영해 시간·돈·노력을 소비하는 방식. 인구통계와 함께 세분화 기준으로 활용 |

### 1. 인지
- 감각적 영역에서 얻는 소리·빛·냄새 등 기본 자극을 감각 기관으로 받아들임
- 마케팅은 감각 기관을 자극하는 접근을 사용: 광고물의 시각적 자극, 매끄러운 재질의 촉감, 음식점의 냄새
- **기계적 노출**: 감각 기관을 통해 광고물을 받아들이는 것
- **인지적 노출**: 전달된 자극을 머리에서 인지할 수 있는 수준의 노출

### 2. 학습
- 제품 구매 이전의 여러 채널 정보와 매장에서의 경험을 통해 이루어짐
- 의도적·목표 지향적 행동만이 아니라 비의도적 행동으로도 학습되며, TV·라디오 광고의 배경음악을 무의식적으로 흥얼거리는 것이 그 예

### 3. 태도
- 광고에 대한 태도가 브랜드 태도로 옮겨 가고 구매 가능성을 높임

### 4. 동기와 개성
- 대표적 개성 유형

| 유형 | 내용 | 광고 시사점 |
| --- | --- | --- |
| 혁신성 | 새로운 것을 추구하는 정도 | 신기술·신제품·새 패션 광고가 효과적 |
| 물질주의 | 제품 소유 성향의 강도 | 판촉 활동의 효과가 높음 |
| 자신감 | 자기 능력·자질에 대한 긍정적 평가 | 자신감 높은 소비자는 단편적 메시지로 설득이 어려워 논리적·구체적 정보 필요, 낮은 소비자는 컨설팅·교육의 잠재 고객 |
| 사회성 | 사회적 관계를 맺고 유지하는 적극성 | 대인 관계의 적극성에 따라 구분 |
| 인지 욕구 | 현상·사물을 인지하려는 욕구의 강도 | 인지 욕구가 강하면 구체적 정보와 논리적 설명이 효과적 |

### 5. 라이프스타일
- 인구통계학적 기준에 더해 라이프스타일의 유사성으로도 소비자를 구분

## 외부적 영향 요인

| 요인 | 내용 |
| --- | --- |
| 물리적 환경 | 소음·혼잡은 집중을 방해하고 구매 결정을 어렵게 함. 빠르고 밝은 음악과 조용하고 느린 음악에 따라 감정과 행동이 달라짐 |
| 문화 | 한 사회의 개성과 같은 것으로, 사회 구성원의 행동·사고에 영향을 주는 사회적 규범과 양식의 체계 |
| 사회계층 | 교육·직업·소득이 유사한 사람들은 구매 취향도 유사. 기업은 특정 계층을 겨냥한 제품과 캠페인을 집행 |
| 준거집단 | 소비자가 닮고 싶고 소속되고 싶은 집단으로 생각과 행동에 영향 |
| 의견 선도자 | 특정 분야의 전문 지식으로 다른 사람의 태도와 행동에 영향, 구전 커뮤니케이션으로 직접적 영향 |
