## 인쇄 매체의 배경

- 광고 메시지를 실어 보낼 매체는 고대의 돌·전단·포스터에서 중세의 신문·잡지, 20세기의 라디오·TV로 확장
- 현재는 인터넷 기반 통신 매체와의 융합으로 컴퓨터·휴대전화 등 뉴미디어의 개별적·결합적 활용이 가능
- 가장 보편적인 구분은 인쇄 매체, 전파 매체, 뉴미디어, 교통·옥외 등 기타 매체
- 매체 간 경계가 허물어져 뚜렷한 구분이 큰 의미를 갖기 어려워지는 추세

## 신문

### 1. 현황
- 현대 광고에서 가장 보편적이고 지속적으로 사용된 매체, 광고 매체로 기능하는 신문은 약 100~130개로 추정
- 국내 최초의 근대적 신문 광고는 1886년 한성주보, 이후 독립신문 등의 창간으로 본격화
- 1995년 전후 증면으로 48~52페이지를 발행
- 2021년 광고비 매출은 전년 대비 7.2% 증가했으나 2022·2023년은 감소 전망
- 원인: 저비용으로 전문성을 살리는 뉴미디어의 잠식, 젊은 층의 종이 신문 대신 인터넷 이용
- 대응: 섹션화, 독자 피드백 강화, 유연한 편집
- 변형 광고의 증가: 지면 양끝·중간의 띠 광고, 한 브랜드를 한 지면에 두 개 이상 게재하는 커플 광고, 단을 벗어난 라인 돌출형, 흑백과 컬러를 활용한 광고, 기사형 광고, 비교 광고

### 2. 규격
- 한 페이지는 세로 15단(51cm), 가로 37cm, 세로 1단은 약 3.4cm
- 기본 단위는 가로 1cm × 세로 1단(3.4cm), 최근에는 인치(1인치 ≈ 2.54cm) 단위도 사용

### 3. 장단점

| 장점 | 단점 |
| --- | --- |
| 대량의 도달 범위 | 오디언스 선택성이 없음(매스 오디언스 대상) |
| 신뢰성(전통 매체, 매체 신뢰도 높음) | 수명이 짧음(며칠을 넘지 못함) |
| 지역성(특정 지역 대상 신문 존재) | 낮은 인쇄·컬러 품질 |
| 즉시성(매일 발행, 메시지 변경이 빠름) | 비용 효율성이 타 매체보다 낮음 |
| 능동적 매체(독자가 직접 찾아 읽음) | - |

### 4. 광고의 종류

| 종류 | 내용 |
| --- | --- |
| 디스플레이 광고 | 헤드라인·본문·그림 등 시각 요소를 담은 흔한 광고 형태 |
| 분류(안내) 광고 | 상품·서비스 종류별로 제시되며 거의 문자로만 구성, 주로 개인·소규모 상인이 이용 |
| 간지 광고 | 미리 인쇄한 광고물을 신문 사이에 끼워 배달 |

### 5. 요금
- 신문마다 독자 수·독자 질·발행 부수가 달라 차이가 큼
- 크기와 게재 지면 위치에 따라 다르며, 조선·중앙·동아의 기준 단가는 비슷함
- 게재 위치, 컬러 사용, 구입량과 시기, 제품 종류에 따라 다양한 할인이 적용되고, 신문사도 매체비 감소를 만회하려 큰 할인을 감수
- 기준 단가와 실제 구매 가격은 차이가 날 수 있음

## 잡지

### 1. 현황
- 1987년 6·29 선언 이후 창간 붐으로 1995년 약 9,700여 개 등록, IMF 위기로 마이너스 성장
- 2021년 광고비 매출은 전년보다 4.3% 감소, 2022·2023년은 소폭 반등 예상
- 잡지사 수는 정체된 반면 광고비가 줄어 업체당 수익은 크게 감소

### 2. 광고의 종류

| 종류 | 내용 |
| --- | --- |
| 블리드 | 배경 이미지가 페이지 가장자리까지 확대, 표현의 유연성과 극적 효과 |
| 삽입 광고 | 별지에 인쇄해 잡지 사이에 끼워 넣음, 특별 요금 |
| 접지 광고 | 지면이 넓어 중앙을 접어 넣은 삽입 광고, 일반적으로 할증 요금 |
| 기사 내 광고 | 기사 50%·광고 50%로 구성, 같은 크기보다 비싼 요금 |

- 이 밖에 입체형, 제품 형태로 디자인한 돌출형, 마이크로칩을 내장해 노래를 들려주는 광고도 등장

### 3. 장단점

| 장점 | 단점 |
| --- | --- |
| 수용자 선별성(세분화된 독자에게 적절한 메시지) | 낮은 도달률(구독 인구 증가가 느림) |
| 색상의 높은 재현성 | 즉시성 부족(월간지는 월 1회 발행) |
| 긴 수명(1~2주에서 1개월 이상) | 구입의 어려움(정기 구독이 아니면 서점 방문) |
| 회독률·재독률이 높음 | 광고 클러터가 높음 |

### 4. 요금과 ABC 제도
- 내지 1페이지 컬러 광고가 주요 잡지 기준 150만~300만원
- 신문과 마찬가지로 노출 효과가 규명되어야 하지만, ABC 제도가 정착되지 않아 발행 부수·독자 수가 정확히 제시되지 않음
- **ABC 제도**: 신문·잡지·웹사이트 등 매체사가 스스로 보고한 부수와 접촉자 수를 표준화된 기준으로 조사·확인해 공개하는 제도
