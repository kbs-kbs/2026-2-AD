## 크리에이티브 메시지의 원천

| 원천 | 내용 |
| --- | --- |
| 제품의 실체 | 버넷: 어떤 제품에도 그 자체의 뉴스가 있으며, 제품과 사실을 파헤치면 뉴스는 발견된다 |
| 제품에 대한 인식 | 실제만큼, 경우에 따라서는 그보다 더 중요. 소비자는 제품을 어떻게 생각하고, 품질을 어떻게 인식하며, 값을 치를 만하다고 보는가 |
| 고객의 욕구와 생활 | 라이프스타일과 습관 파악, 소비자와의 깊은 대화에서 통찰을 얻음 |
| 경쟁사와의 차별화 | 경쟁자가 누구이며 무엇을 제안하는가, 우리 제품을 사게 하는 주요 이익은 무엇인가 |

### 1. 제품에 대한 인식
- 제품 속성과 소비자의 심층적·궁극적 가치를 연결하고 잠재된 감성을 찾는 것이 중요
- 래더링 기법을 응용하거나 의미망 분석을 사용
- 의미망 분석 예(딤채): 1도 내 온도 편차 유지 → 살아 있는 김치 맛 → 밥맛 상승 → 건강 / 용적률 → 많은 김치 저장 → 사용의 편리 / 브랜드 파워 → 만족도 1위 → 우월감 → 자아 실현

### 2. 고객의 욕구와 생활
- 모든 통계는 유용하지만, 욕구와 필요가 왜 다른가를 분석해야 함
- 제품을 가장 많이 구매하는 사람이 누구인지, 나이·소득·교육 수준은 어떤지 확인

## 편익의 발견

| 편익 범위 | 내용 | 예 |
| --- | --- | --- |
| 물리적 편익 | 돈과 시간을 절약, 건강에 좋음 | 저지방·고단백, 간편한 요리 |
| 감각적 편익 | 고급스러운 맛, 흥미로운 감촉 | 기름기와 비린내가 제거된 담백한 맛 |
| 사회적 편익 | 가족·동료로부터 인정 | 가족 모두가 즐길 수 있음, 친교의 분위기 |
| 자아 만족 | 좋은 어머니로서의 자존심, 성취감 | 가족 입맛을 만족시키는 현명한 주부 |

### 편익의 조건
- 소비자의 문제를 해결하거나 생활을 더 쉽게 만들어야 함
- 소비자는 제품 안에 무엇이 있는지가 아니라 '그 안에 내게 필요한 것이 무엇인가'를 봄
- 믿을 수 있고 설득적인 전략으로 제시된 **단 한 가지** 편익이어야 함

## 편익의 전달

### 1. 생생한 전달
- '부드럽고 깨끗하다'처럼 일반적이고 추상적인 편익은 소비자가 경쟁사와 차별화하지 못하게 함
- 구체적이고 살아 있는 편익이어야 함

### 2. 편익의 근거
- 왜 그런 편익을 준다고 제안할 수 있는지 이유를 밝혀야 함
- 약속한 것을 어떻게 제공할 수 있는지 간단히 설명
- 근거 없는 약속은 공허한 껍데기
- 예: 엑세드린 "어린이가 꺼내 삼킬 수 없도록 보호합니다" → 근거: 어린이는 거의 열 수 없고 어른은 쉽게 열 수 있는 안전장치 뚜껑

## 광고의 이미지

### 1. 브랜드의 개성
- 소비자가 제품을 경쟁사와 쉽게 구별하게 하고 브랜드에 생명과 정신을 불어넣는 것
- 제품과 브랜드의 의미에 맞는 개성과 이미지를 유지하고 통합적·일관되게 관리

### 2. 제품 범주의 의미
- 내 브랜드의 개성을 알려면 먼저 어느 제품 범주에 속하는지 파악
- FCB 그리드 모형을 축으로 고관여·저관여, 이성·감성의 네 분면에 위치한 제품군은 소비자가 보는 이미지가 다름
- 고관여 제품(자동차, 고급 패션)은 전문적 이미지, 저관여 제품(맥주)은 친근한 이미지

### 3. 제품의 의미
- 물리적 속성과 편익은 이해하기 쉽지만 심리적 의미는 구매 동기와 연결되어 파악이 어려움
- 제품의 의미는 슬로건으로 나타나기도 하고, 대개 광고의 개성·이미지로 표현되며 브랜드명 결정과도 연결
- 예: 맥주 → 신선함, 축제 분위기, 젊음, 공유, 활력

### 4. 브랜드 의미
흔히 브랜드 의미 또는 브랜드 자산이라 부르며 세 부분으로 구성된다.

| 구성 | 내용 |
| --- | --- |
| 브랜드 헤리티지 | 어느 상표가 왜 탄생했고 오늘까지 무엇이 상표를 지탱해 왔는가 |
| 브랜드 에센스 | 브랜드를 들었을 때 제일 먼저 떠오르는 그 무엇 |
| 브랜드 개성 | 브랜드가 사람이라면 어떤 사람인가 |
